## Projets personnels

### [Colin-Malin — App Quiz](https://colin-malin.vercel.app/)
**[Frontend](https://github.com/CodeRonin-VCO/colin-malin-client) · [Backend](https://github.com/CodeRonin-VCO/colin-malin-server)**

**Technologies :** React 19, Vite, Jotai, Chart.js, Node.js, Express 5, PostgreSQL, Sequelize, JWT, Argon2

**Déployé sur :** Vercel (frontend) · Railway (backend + PostgreSQL)

**Description :** Application de quiz interactive permettant aux utilisateurs de créer un compte, de jouer des parties personnalisées (thème, difficulté, nombre de questions) et de consulter leurs statistiques détaillées via un dashboard.

Fonctionnalités clés :
- Authentification JWT avec expiration et éjection automatique
- Espace admin (gestion des questions)
- Dashboard de statistiques (graphiques par thème, difficulté, évolution dans le temps)
- Architecture REST complète : controllers / services / models
- Sécurité : Helmet, express-rate-limit, Argon2
- Tests unitaires et d'intégration (Jest, Supertest)
- Responsive design (mobile + desktop)
